# Starter Pack : la chaise Atto

Ressources fournies par Anthony, le designer : le process réel de sa chaise **Atto**, du croquis à la découpe CNC.

| Dossier | Contenu |
|---|---|
| `01_Inputs_Croquis/` | **ton entrée** : `sktech_chaise_atto.jpg`, croquis au feutre, 3 vues sur la même feuille (profil, 3/4 face, 3/4 dos) |
